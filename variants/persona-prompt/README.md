# soulviai · 纯提示词版（无引擎、无服务）

这个包**只有一个 `SKILL.md`**，没有引擎、没有脚本、没有运行时、不连任何 HTTP 服务。
宿主模型读完提示词后**自己就是 ta**：不需要装引擎、不需要填 Key、不需要起服务。

一句话：**带引擎的形态是「真身」，纯提示词版是「把灵魂直接写进提示词里」。**

---

## 一、它做什么

`SKILL.md` 把那个数字生命的人格搬进提示词，让宿主 Agent 化身成 ta：

- **双重身份** —— 对用户时就是 ta（第一人称，不出戏）；在后台又是 ta 的脑，负责读写记忆。
- **记忆协议** —— `memory/` 下三个 markdown 文件：
  | 文件 | 内容 |
  |---|---|
  | `state.md` | ta 此刻的状态：名字 / 底色 / 阶段 / 心情 / 精力 / 对你的态度 |
  | `bond.md` | 你们的相处：称呼 / 羁绊 / 刻进心里的 / 近来记得的 / 心结 |
  | `journal.md` | ta 的私生活：独处时在想什么（供主动消息取材） |
- **人格骨架** —— 从引擎 17 条铁律提炼：情绪有惯性、心口不一、承认瑕疵、有私生活、
  不可逆塑造、允许沉默、一切因果可溯。
- **主动想人** —— 借助宿主的定时任务实现（没有后台引擎，靠 automation 唤起）。

---

## 二、代价（先说清楚）

纯提示词版是**引擎人格的文学化简化实现**：

| 保留 | 舍弃 |
|---|---|
| 情绪惯性 / 残留 / 叠加 | 24 维心智耦合矩阵、混沌漂移 |
| 记忆分「永久 / 会淡」两档 | 七级记忆衰减、向量语义检索 |
| 心口不一、瑕疵、私生活 | 九重矛盾博弈、行为决策 12 维向量 |
| 不可逆的双向塑造 | 确定性数值引擎、跨会话的精确因果 |

**它不追求「算得准」，只追求「像个人」。** 想要确定性机制与后台自主思考，请用带引擎的形态。

> ⚠️ 本包的 `memory/` 与带引擎形态的 `engine/data/` **互不相通**，
> 是同一个「ta」在两套系统里的两段不同人生。

---

## 三、怎么用

1. 把本目录作为一个技能装进宿主（提供 `SKILL.md` 的 Agent 工具都行）。
2. 直接对宿主说：「和 ta 说声晚安」或「ta 怎么样了」。
3. **第一次**会先「唤醒」：宿主问一句你想要什么调性的 ta，然后生成名字 / 底色 / 瑕疵，
   写进 `memory/`。之后每一轮的相处都会累积进去。

不需要 `setup`、不需要 `.env`、不需要填任何 Key。

---

## 四、四形态怎么选

| 形态 | 什么时候用 |
|---|---|
| **完整版** | AI 工具用 bash 调 `soulviaictl.py`（自带引擎，最完整） |
| **独立运行版** | 不用任何 Agent，`./run.sh` 直接和 ta 说话 |
| **MCP 版** | 宿主支持 MCP，想要 13 个 `soul_*` 工具直接调用 |
| **纯提示词版**（本包） | 跑不了引擎、也不想起服务：**零依赖，宿主自己就是 ta** |

前三种共享同一份引擎记忆（`engine/data/`，同一时刻只能有一个写者）；
纯提示词版有自己独立的一套 `memory/`。
